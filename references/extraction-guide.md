# 약관 → 제품 JSON 추출 지침 (AI가 직접 읽고 쓴다)

개인정보처리방침 본문(`data/policies/…txt`)을 읽고 `data/products/제품id.json`을 만든다.
외부 API나 별도 모델은 쓰지 않는다. 본문에 없는 내용은 **"미기재"**(근거표용) 또는 **"[확인 필요]"**(동의서에 찍히는 값)로 두고 지어내지 않는다.

## 1. `_extracted` — 약관에서 뽑는 10개 항목 (근거표에 그대로 실린다)

항목마다 `{"value": "...", "quote": "근거 문장(조항 번호·섹션 제목 + 원문 한 문장, 토씨 그대로)"}` 꼴로 쓴다.

| 키 | 뽑을 것 |
|---|---|
| vendor | 운영 회사·기관명, 소재 국가, 국내대리인(해외 서비스면) |
| foreign | true/false. **true 조건**: ①운영사가 해외 법인 ②국외 이전 조항 ③해외 서버·클라우드 명시 ④해외 AI·클라우드 업체에 이전·위탁 명시, 넷 중 하나라도 근거가 있을 때만 |
| country | "본사 대한민국 / 일부 국외이전: 미국(OpenAI)"처럼 본사 국가와 이전 국가를 구분 |
| items | **학생(아동) 계정 또는 교사가 만들어 주는 학급 계정 기준** 수집 항목. 학생용 표가 따로 있으면 그 표 우선. 교사·통합회원·결제·마케팅 항목은 빼고 notes에 뺐다고 적는다 |
| purpose | 수집·이용 목적 요약 한 줄 |
| retention | 서비스가 정한 보유·이용 기간 |
| third_party | 제3자 제공 대상과 목적. 없으면 "동의 또는 법령 외 제공 없음" |
| outsourcing | 처리 위탁 수탁사와 업무. 국외 이전이 있으면 이전받는 자·국가·항목도 여기 |
| children | 만 13세/14세 미만 가입 정책, 법정대리인 동의 방식, 학교·교사 대리 동의 조항 |
| dpo | 개인정보 보호책임자·문의처(국내대리인 포함) |
| notes | 교사가 동의서 쓸 때 주의할 점 1~3줄 (뺀 항목, 미기재 항목, 확인할 곳) |

근거(quote) 검증: 쓴 뒤 본문에서 `grep`으로 실제 있는 문장인지 확인한다. 없으면 고친다.

## 2. 상단 필드 — 동의서에 찍히는 값 (학부모가 읽는 글)

| 키 | 규칙 |
|---|---|
| name | 7자 안팎으로 줄 나눔: `"패들렛\n(Padlet)"`, `"구글\n워크스페이스\n(교육용)"` |
| vendor | 운영사(국가) |
| foreign / country | 위 조건대로 |
| purpose | "교육과정 운영 및 ○○ 교과 활동, ○○ 학생 계정 생성 및 학습 관리" 꼴 한 줄 |
| items | "성명, 학년, 반, 번호" + 그 서비스 고유 항목(학교 계정 이메일, 작품, 학습 이력 등). IP·쿠키·OS·기기정보 같은 자동수집 항목은 넣지 않는다. 60자 안팎. 비회원(참여 코드·닉네임) 서비스는 "닉네임(실명 대신 별명 권장), 점수·순위" |
| retention | "해당 학년도 교육과정 종료 시까지" (학교 기준 고정) |
| third_party | receiver 운영사(국가) / purpose "○○ 서비스 내 학생 계정 생성 및 서비스 제공" / items·retention은 위와 같게 |
| transfer | `foreign: true`일 때만. receiver(국가), country_method, items, retention. 서버 국가가 불명확하면 "제품(국가)에서 제공하는 클라우드 서버에 저장(서비스 제공자의 서버 위치에 따라 변경 가능)" |
| _source | url, policy_version(시행일), policy_file(상대경로), extracted_at(YYYY-MM-DD), method("AI가 약관 본문을 읽고 추출, 사람이 검수") |
| _review_required | 항상 true |

본보기: `data/products/canva.json`(해외), `data/products/toctocmath.json`(국내 공공), `data/products/quizn.json`(비회원 참여형).
빈 틀: `data/products/_template.json`.
